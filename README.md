# E-Commerce Web Application

## Project Overview
The E-Commerce Web Application is a full-stack online shopping platform developed to manage products, users, carts, and orders. The application provides a smooth shopping experience with secure authentication and responsive design.

---

# Features

- Product Catalog Management
- Add to Cart Functionality
- Checkout System
- User Authentication & Authorization
- Role-Based Access (Admin/User)
- Order Tracking
- Backend APIs for Products & Orders
- Responsive Design for Mobile and Desktop

# Installation

## Clone Repository

```bash
git clone https://github.com/your-username/ecommerce-web-app.git
```

## Install Dependencies

### Frontend
```bash
cd client
npm install
```

### Backend
```bash
cd server
npm install
```

---

# Run the Application

## Start Backend Server
```bash
npm start
```

## Start Frontend
```bash
npm run dev
```
